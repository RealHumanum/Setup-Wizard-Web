# Apex Wizard - Promotional Website

This repository contains the source code for the promotional website and privacy policy for the **Apex Wizard** iOS application. 

## About the App
**Apex Wizard: Moto Performance** is a premium, native iOS application designed for motorcycle enthusiasts and track riders to manage, optimize, and troubleshoot their bike's performance.

## Files
- `index.html`: The main promotional landing page.
- `privacy.html`: The Privacy Policy for the App Store submission.

## Deployment
This website is hosted for free using **GitHub Pages**. 

The live site can be accessed at: 
- Support URL: `https://RealHumanum.github.io/Apex-Wizard-Web/`
- Privacy Policy URL: `https://RealHumanum.github.io/Apex-Wizard-Web/privacy.html`

To update the website, simply commit changes to the `main` branch, and GitHub Pages will deploy them automatically.
